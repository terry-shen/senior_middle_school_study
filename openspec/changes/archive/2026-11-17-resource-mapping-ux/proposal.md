## Why

资源映射工作台当前把「归属 / 学生可见 / 精选 / 生命周期」四个互相独立的维度，用 8 个同权重按钮堆在页面上，表格又不显示"学生到底能不能看到"，管理员无法判断每个操作的实际效果。数据现状放大了问题：未映射的 38,843 条资源里，教师侧占 13,066 条（确认了也不会给学生看），`教辅资料合集` 单个目录就有 28,927 条旧版教辅——按文件逐条勾选是没有出口的。

## What Changes

- 映射工作台改为**任务导向的三步流程**：目录清理 → 未映射收件箱 → 单节收敛
- 新增**单节收敛工作台**：左侧该节候选资源（已挂 / 待定），右侧实时预览"学生端将看到什么"，每节状态灯显示精选数与可用数是否达标
- 表格新增**「学生可见」列**，用 `✅ 可见 / ⚠ 未挂载 / ⬜ 未确认 / 🚫 教师资源 / 🚫 已归档` 取代含糊的"状态"
- 批量操作按维度分组并配一行「实际效果」说明；`挂到选中节` 之后不再需要重复点`确认映射`
- 新增**目录级批量操作**（按路径前缀归档 / 屏蔽 / 恢复），用于一次性收敛旧版教辅目录
- 危险操作（解除映射、屏蔽）移入次级菜单，执行后提供 5 秒撤销
- 保留现有全表格视图作为「高级视图」，供熟练用户使用

## Capabilities

### New Capabilities
（无）

### Modified Capabilities
- `netdisk-index`: 新增「资源映射收敛工作台」要求（目录级批量、单节收敛与学生端预览、学生可见状态呈现、操作影响提示与撤销）；扩展现有「资源精选、归档与屏蔽」要求以支持按目录批量生效

## Impact

- 后端 `backend/src/routes/netdisk-index.ts`：新增目录聚合统计、目录级批量操作、单节收敛详情（候选 + 状态指标）、批量操作撤销接口
- 后端 `backend/src/services/netdisk-index-service.ts`：目录分组统计、按路径前缀批量、单节候选推荐（复用 `computeVideoCandidates` / `computeCandidates`）、操作前后状态快照
- 前端 `frontend/src/pages/NetdiskMapping.tsx` + `.css`：重构为三步 Tab（目录清理 / 未映射收件箱 / 单节收敛）+ 高级表格视图；新增学生端预览面板
- 前端 `frontend/src/services/netdisk-index-api.ts`：新增对应 API 函数与类型
- 不改数据库 schema，不改变既有学生端可见性规则（`status=active AND audience in (student,both) AND mapConfirmed=true`）
- 不下载/复制网盘文件，不动 `netdisk_assets` 已有数据（除管理员主动执行批量操作）
