## Context

资源映射工作台目前只认 `sectionId`：挂到小节就是已映射，未挂小节就进入收件箱。教辅资源线的系列/书目是运行时从路径推导的，管理员无法纠正错误分组。需要在同一条资源上支持两种映射目标，并保存手动结果。

## Goals / Non-Goals

**Goals:**

- 单条与批量把资源归入教辅系列/书目
- 手动教辅分类持久化，并优先于路径推导
- 归入教辅时清空教材小节归属；改回小节时清空教辅分类
- 不改变视频主线判定

**Non-Goals:**

- 不新增教辅分类字典表；系列/书目仍是自由文本
- 不改学生端阅读器
- 不改自动扫描的章节候选算法

## Decisions

### 用两个可空字段保存手动分类

新增 `librarySeries`、`libraryBook`。为空表示继续按路径推导，非空表示管理员手动指定。这样现有 4 万多条自动分组资源不需要回填，也不会丢失。

### 两种目标互斥

一条资源只属于一个映射目标：

- 教材小节：写 `sectionId`，清空 `librarySeries/libraryBook`
- 教辅资源：写 `librarySeries/libraryBook`，清空 `sectionId`、`isPinned`，`status=active`

批量操作按同样规则执行。视频主线不在本功能中手动调整。

### 映射页增加教辅目标入口

在未挂小节收件箱和高级表格中增加「归入教辅」操作：单条用行内表单，批量用统一的系列/书目输入。高级表格增加「主线」列，显示教材小节 / 视频主线 / 教辅资源线 / 未归主线。

## Risks / Trade-offs

- 系列/书目是自由文本，可能出现近似重名 → 后续可加下拉建议，但首期允许手动输入
- 批量操作会清空小节归属 → 操作前显示影响条数，沿用现有撤销机制
- 手动分类后自动扫描不能覆盖 → 扫描逻辑需判断 `librarySeries/libraryBook` 是否非空

## Migration Plan

1. `prisma db push` 增加两列，默认 null。
2. 后端先发布映射接口与优先读取逻辑。
3. 前端随后发布映射页入口。
4. 回滚只回代码，新增列可保留。
