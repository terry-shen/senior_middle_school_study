# 用户使用手册

## 1. 系统简介

高中数学学习系统是一个基于AI的智能学习辅助平台，帮助学生提升数学知识点掌握度、提高成绩、识别知识短板。

## 2. 角色说明

### 管理员（教师）
- 管理学生账号和班级
- 导入试卷和题目
- AI分析试题（知识点/解析/答案/难度）
- 自动出卷和模拟考试
- 发布在线测验
- AI批改和审核
- 查看班级学习统计

### 学生
- 参加在线测验和模拟考试
- 查看掌握度报告
- 使用错题本复习
- 获取个性化推荐
- 查看知识地图
- 每日打卡和获取徽章

## 3. 管理员指南

### 3.1 学生管理
1. 进入"学生管理"页面
2. 点击"批量导入"上传CSV/JSON文件
3. 创建班级后可分配学生到班级
4. 支持导出学生列表

### 3.2 试卷导入
1. 进入"试卷导入"页面
2. 上传PDF或图片格式的试卷
3. 系统自动OCR识别文字
4. 点击"拆分"将试卷拆分为独立题目
5. 支持后续AI分析

### 3.3 AI分析
1. 进入"AI分析"页面
2. 选择待分析的题目
3. 点击"单个分析"或"批量分析"
4. AI自动识别知识点、生成解析和答案
5. 在"审核"标签页审核AI生成的内容

### 3.4 自动出卷
1. 进入"自动出卷"页面
2. 设置参数：
   - 总分、题型分布
   - 难度分布（简单/中等/较难/困难）
3. 点击"预览"查看题目
4. 点击"生成"创建试卷
5. 可导出PDF或Word

### 3.5 在线测验
1. 进入"在线测验"页面
2. 选择题目创建测验
3. 设置考试时长
4. 分配给班级
5. 点击"发布"
6. 学生即可参加测验

### 3.6 AI批改
1. 学生提交测验后，进入"AI批改"页面
2. 选择测验记录
3. 点击"批量批改"
4. 选择题自动判分，填空题AI等价识别，解答题步骤评分
5. 可手动调整分数

## 4. 学生指南

### 4.1 参加测验
1. 在导航栏点击"在线测验"
2. 选择待参加的测验
3. 选择题点击选项作答
4. 填空题输入文字
5. 解答题可拍照上传（支持手机拍照）
6. 点击"提交"完成测验

### 4.2 查看掌握度
1. 点击"掌握度"查看报告
2. 查看各知识点掌握等级（优秀/良好/一般/较差）
3. 系统自动识别薄弱知识点
4. 可生成学习报告

### 4.3 知识地图
1. 点击"知识地图"
2. 四种视图：
   - 树形图：知识点层级结构
   - 地图视图：区域大小表示重要性
   - 雷达图：与班级平均对比
   - 仪表盘：掌握度总览
3. 颜色表示掌握度（红→黄→绿）
4. 点击节点查看详情

### 4.4 错题本
1. 点击"错题本"查看错题列表
2. 按知识点/题型/难度筛选
3. 点击"重练"练习错题
4. 可生成变式题
5. 标记复习状态（未复习/复习中/已掌握）

### 4.5 智能推荐
1. 点击"智能推荐"获取每日推荐
2. 系统根据掌握度、错题、难度自动推荐题目
3. 可选择"专项突破"针对特定知识点
4. 点击题目开始练习
5. 练习后可反馈（有帮助/不再推荐）

### 4.6 学习路径
1. 点击"学习路径"查看推荐路径
2. 系统按知识点依赖关系排序
3. 优先推荐薄弱知识点
4. 完成一项后自动解锁下一项
5. 显示进度条和目标掌握度

### 4.7 模拟考试
1. 点击"模拟考试"选择考试
2. 限时作答，有倒计时
3. 可使用答题卡快速跳转
4. 可标记题目回头再看
5. 提交后查看成绩和排名
6. 查看对标分析和错题分析

### 4.8 学习激励
1. **每日打卡**：每天登录后打卡，连续打卡有奖励
2. **徽章系统**：练习次数、掌握度提升、连续打卡等成就
3. **排行榜**：班级排名（匿名）和全局排名
4. **挑战活动**：参加班级PK和挑战赛
5. **通知**：查看徽章获得、打卡提醒等通知

## 5. 常见问题

### Q: 忘记密码怎么办？
联系管理员重置密码。

### Q: 测验中途断网怎么办？
系统自动保存答案，重新连接后可继续答题。

### Q: 手机拍照上传失败？
确保图片大小不超过10MB，网络连接稳定。建议在WiFi环境下使用。

### Q: AI批改的分数不准确？
管理员可以手动调整分数。解答题的AI批改仅供参考。

### Q: 推荐的题目太难/太简单？
可以在练习后点击"反馈"，选择"不再推荐"或调整偏好。
